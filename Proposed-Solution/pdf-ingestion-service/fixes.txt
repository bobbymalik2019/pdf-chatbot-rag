Two problems that require different solutions
Problem A — Slow processing

Ollama may take a long time to generate embeddings for 1,313 chunks.

Solutions include better batching, measuring throughput, reducing unnecessary chunks, and evaluating faster embedding engines.



Problem B — Unresponsive UI

Our upload currently uses a request-response workflow. The user may see a loading state for the entire ingestion duration.

A long-running request doesn't necessarily block React's rendering thread, so we must establish whether the UI actually freezes or simply offers no usable progress feedback.
